# Turnkeel

**Whose turn is it?**

It runs on your machine with one command, with no account, or on your own server when people help you. It is open source, there is no hosted version, and telemetry is off.

- [turnkeel.com](https://turnkeel.com): the website, with [getting started](https://turnkeel.com/getting-started/) and the [docs](https://turnkeel.com/docs/).
- [CONTRIBUTING.md](CONTRIBUTING.md): how to work on it.
- [CHANGELOG.md](CHANGELOG.md): what changed in each version.
- [SECURITY.md](SECURITY.md): how to report a vulnerability.
- Questions and reports: support@turnkeel.com.
